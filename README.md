## 🎮 Tentang Game

**Shinobi Senki 8-bit** adalah game arena pertarungan 2D bergaya retro 8-bit di mana **kamu tidak mengendalikan siapa pun** — 8 ninja orisinal bertarung sendiri-sendiri dengan AI yang super cerdas. Pilih mode, pilih ninja favoritmu, lalu saksikan pertempuran epik dengan komentator, kill feed, dan statistik live!

100% offline, tanpa iklan, tanpa pay-to-win. Murni tontonan seru~

## 📲 Cara Install APK

1. Download **ShinobiSenki.apk** dari [halaman Releases](https://github.com/Wilykun/Naruto-senki-8bit/releases/latest)
2. Buka file-nya di HP
3. Izinkan **"Install dari sumber tidak dikenal"** kalau diminta
4. Main!

> Butuh Android 7.0+ (API 24). APK ini debug-signed, aman buat pribadi — bukan dari Play Store.

## 🖥️ Main di PC / Browser

Punya file `assets/index.html`? Bisa juga dibuka langsung di browser — 100% offline:

```bash
# Cara 1: buka langsung
# klik dua kali assets/index.html

# Cara 2: pakai server lokal
python3 -m http.server 8080
# buka http://localhost:8080/assets/
```
