## Tentang Game

**Shinobi Senki 8-bit** adalah game arena pertarungan 2D bergaya retro 8-bit di mana **kamu tidak mengendalikan siapa pun** — 16 ninja orisinal bertarung sendiri-sendiri dengan AI yang super cerdas. Pilih mode, tebak pemenangnya, lalu saksikan pertempuran epik dengan komentator, kill feed, dan statistik live!

100% offline, tanpa iklan, tanpa pay-to-win. Murni tontonan seru~

### Install APK di Android
1. Download **ShinobiSenki-v*.apk** dari [halaman Releases](https://github.com/Wilykun/Naruto-senki-8bit/releases/latest)
2. Buka file-nya di HP
3. Izinkan **"Install dari sumber tidak dikenal"** kalau diminta
4. Main!

> Butuh Android 7.0+ (API 24). APK ini debug-signed untuk pemakaian pribadi.

## Fitur

- **16 ninja orisinal** — tiap ninja punya 2 jutsu unik + gaya bertarung beda
- **5 tingkat AI** — GAMPANG, MUDAH, NORMAL, SULIT, EXTREM (atur di menu awal)
- **Taruhan tebak pemenang** — pilih jagoanmu sebelum match, kumpulkan statistik menang/kalah/streak
- **7 mode permainan** — Duel 1v1, Team 3v3, Deathmatch, Tournament, Survival, Boss Raijin, Liga
- **AI super cerdas** — tiap ninja punya persona: agresif, defensif, licik, seimbang
- **Kamera auto-lock** — otomatis mengikuti aksi terpanas; matikan untuk geser manual (drag di HP, panah di PC)
- **Statistik live** — kill, assist, damage, kill feed, komentator (urut kill terbanyak)
- **Slow-mo FINISH** — momen KO penentu diperlambat dramatis
- **Stage hazard** — angin, hujan petir, heal orb
- **Kecepatan 1x/2x/4x** — atur tempo pertandingan
- **Ramah mobile** — menu dioptimasi buat layar sentuh

## Untuk Developer (Fork)

Mau modifikasi atau bikin versi sendiri? Gampang!

1. **Fork** repo ini ke akun GitHub-mu (tombol Fork di kanan atas)
2. Game-nya cuma **satu file**: `index.html` di root — buka langsung di browser, 100% offline, tanpa build step
3. Untuk versi web: aktifkan **Settings → Pages → Deploy from branch → main → / (root)**. Gamenya live di `https://<username>.github.io/<repo>/`
4. Untuk versi APK: fork sudah termasuk workflow GitHub Actions — buka **Actions**, enable workflow, lalu **Run workflow**. APK jadi otomatis (±2 menit), download di tab Artifacts
5. Semua logika game ada di satu `<script>` dalam `index.html` — silakan utak-atik!

Tidak perlu install apa-apa untuk main di browser. Untuk build APK tidak perlu install Android Studio — GitHub Actions yang kerjakan.
